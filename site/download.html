تحميل APK — 1.0.0 كل الإصدارات

المتطلبات

أندرويد 6.0 (API 23) أو أحدث · مساحة فارغة ~120 ميجابايت · اتصال بالإنترنت للمشاهدة والتنزيل.

التوقيع والسلامة

الحزمة مبنية على GitHub Actions من الكود المصدري، وموقّعة بمفتاح الإصدار. المصدر الرسمي الوحيد هو هذه الصفحة أو إصدارات GitHub.

التحديثات

بعد التثبيت، ستظهر التحديثات داخل التطبيق مع ملاحظات الإصدار وشريط تنزيل ومثبّت مباشر.

خطوات التثبيت

  1. اضغط «تحميل APK» وانتظر انتهاء التنزيل.
  2. افتح الملف من إشعار التنزيل أو من مجلد Downloads.
  3. إن ظهر تحذير، اختر «الإعدادات» ثم فعّل «السماح من هذا المصدر».
  4. اضغط «تثبيت» ثم «فتح».
  5. سجّل الدخول أو تابع كزائر، وابدأ من تبويب «الأحدث».

ملاحظة: تحديث التطبيق لاحقًا يتطلب نفس توقيع الحزمة. إن ثبّت نسخة قديمة بتوقيع مختلف، أزلها أولًا.

هل تحتاج معمارية أخرى؟ إصدارات GitHub تتضمن حزمًا لكل معمارية (arm64-v8a، armeabi-v7a، x86_64) وحزمة AAB للمتاجر.
