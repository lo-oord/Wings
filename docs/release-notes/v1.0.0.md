# Wings 1.0.0 — الإصدار الأول 🎉

أهلاً بك في Wings. هذا أول إصدار مستقر، ويجمع كل ما بُني حتى الآن في تجربة واحدة.

## الجديد
- **مكتبة أنمي عربية** مع الأحدث، الاستكشاف، البحث، التصنيفات وتفاصيل كاملة لكل عمل.
- **مشغّل حلقات** يدعم الجودات المتعددة، التقديم/التأخير، الترجمة، والتشغيل في نافذة عائمة.
- **تنزيلات** للمشاهدة دون اتصال، مع إيقاف واستكمال.
- **المجتمع**: منشورات، ريلز، تعليقات، إعجابات، حفظ، هاشتاجات، وإشعارات.
- **محرر صور** مدمج لقص وتدوير وضبط منشوراتك قبل نشرها.
- **محادثات** فردية مع مشاركة المنشورات والريلز داخل الدردشة.
- **الملف الشخصي** مع المتابِعين والمتابَعين والشارات.
- **تجربة داكنة/فاتحة** بالهوية الخضراء، ودعم كامل للعربية والإنجليزية.

## التحسينات
- حركات وضغطات ناعمة، واحترام «تقليل الحركة» في النظام.
- تحميل صور أسرع واستهلاك ذاكرة أقل.
- طلبات شبكة أقل: لا تكرار لنفس الصفحة، وذاكرة تخزين مؤقت أذكى.

## ملاحظات
- يتطلب Android 6.0 أو أحدث.
- التحديثات القادمة ستظهر داخل التطبيق مع شريط تنزيل ومثبّت مباشر.

شكرًا لأنك جزء من Wings. 🕊️
